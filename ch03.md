## compare What elasticity measures and its degrees | 68-85
- * def Elasticity of demand :: The degree to which quantity demanded reacts to a change in price - the law of demand gives the direction, elasticity gives the size.
- * Three demand elasticities: price (% change in Qd / % change in own price), income (% change in Qd / % change in income), cross (% change in Qd of X / % change in price of Y).
- Elastic = sensitive to price; inelastic = insensitive.
- Elasticity is unit-free, so it compares goods measured in different units (sticky note).
- eg A firm planning a price rise must know how far sales will contract - depends on brand loyalty, buyers' income group, weather and number of substitutes.
| Absolute value | Degree | What happens | Price and total revenue |
| E = 0 | Perfectly inelastic | Quantity does not change at all (vertical curve) | Revenue moves with price |
| 0 < E < 1 | Relatively inelastic | % change in Q smaller than % change in P | * Same direction |
| E = 1 | Unit elastic | % change in Q equals % change in P | * Revenue unchanged |
| E > 1 | Relatively elastic | % change in Q bigger than % change in P | * Opposite directions |
| E = infinity | Perfectly elastic | Tiny price change, huge quantity change (horizontal curve) | - |
- * The minus sign only shows the downward slope; the size of elasticity is the absolute value.
- tip Elastic: cut price to raise revenue. Inelastic: raise price to raise revenue.

## rule Total expenditure (total outlay / revenue) method | 69-70
- * Proposed by Alfred Marshall: compare total spending (price x quantity) before and after a price change.
- * Price falls and total spending rises -> relatively elastic.
- * Price falls and total spending falls -> relatively inelastic.
- * Price falls and total spending stays the same -> unit elastic.
- x Gives only a rough indication (direction of elasticity), not a precise number.
- eg Price falls 10% and spending also falls 10% -> quantity bought has not changed at all -> perfectly inelastic.
- ! "Total savings" is not a method of measuring elasticity; total outlay, point and arc are.

## formula Percentage (midpoint) method | 71
- * Uses averages of the two quantities and two prices so the answer is the same whichever direction you move.
- f Price elasticity (midpoint) :: [(Q2 - Q1) / ((Q1 + Q2) / 2)] / [(P2 - P1) / ((P1 + P2) / 2)] :: Q = quantity demanded, P = price, 1 = old, 2 = new :: P 200 -> 400, Q 30 -> 10: (-20 / 20) / (200 / 300) = -1 / 0.667 = -1.5 -> elastic :: Report the absolute value; keep the averages in both denominators
- eg Same price rise, Q 30 -> 25: (-5 / 27.5) / 0.667 = -0.18 / 0.667 = -0.27 -> inelastic.
- eg Same price rise, Q 30 -> 15: (-15 / 22.5) / 0.667 = -0.667 / 0.667 = -1 -> unit elastic.

## formula Point, arc and geometric methods | 72-73
- * Point elasticity - for very small price changes (e.g. petroleum products); measured at one point on the curve using the ORIGINAL price and quantity.
- f Point elasticity :: (dQ / dP) x (P / Q) = [(Q1 - Q0) / Q0] / [(P1 - P0) / P0] :: Q0, P0 = original quantity and price; dQ = Q1 - Q0, dP = P1 - P0 :: P 12 -> 11.75, Q 100 -> 101: (1 / -0.25) x (12 / 100) = -4 x 0.12 = -0.48 -> inelastic :: Use the original P and Q, not averages
- * Arc elasticity - for large price changes over a range (poultry, dairy, crops), between two distinct points.
- f Arc elasticity :: [(Q1 - Q0) / (Q1 + Q0)] x [(P1 + P0) / (P1 - P0)] :: 0 = start point, 1 = end point :: P 8 -> 12, Q 300 -> 100: (-200 / 400) x (20 / 4) = -0.5 x 5 = -2.5 -> elastic :: The two halves are flipped - sums of prices go on top
- f Geometric (point on a straight-line curve) :: Lower segment of the demand curve / upper segment :: Lower = part below the point down to the quantity axis; upper = part above it up to the price axis :: At the midpoint the two parts are equal -> E = 1; above midpoint E > 1; below midpoint E < 1 :: Elasticity changes along a straight line even though slope is constant
- eg Price elasticity -1.5, price cut from 1.00 to 0.90 (-10%): sales rise 1.5 x 10% = 15%, so 10,000 units become 11,500 units.
- eg Price 35 -> 40 (+14.29% on original), quantity 1,400 -> 1,200 (-14.29% on original): elasticity = -1.

## formula Income elasticity of demand | 74-75
- * Measures how demand responds to a change in consumers' income - positive for normal goods, negative for inferior goods.
- f Income elasticity :: % change in quantity demanded / % change in income :: Midpoint averages used for both changes :: Income 10,000 -> 15,000, Q 50 -> 40: (-10 / 45) = -22.2%; (5,000 / 12,500) = 40%; -22.2 / 40 = -0.56 -> inferior and inelastic :: The SIGN tells the type of good; the size tells the strength
- * Normal goods: positive; superior / luxury goods rise more than in proportion to income (elastic, e.g. luxury cars); necessities are income-inelastic.
- * Inferior goods: negative - cheap food, frozen food, long-route bus tickets, reconditioned cars.
- * Uses: high-income-elasticity products are hit hardest in a recession (cars fell more than food in COVID-19); firms forecast demand and shift resources towards high-income-elasticity products as the economy grows.

## formula Cross elasticity of demand | 75-76
- * Measures how purchases of one good respond to a change in another good's price; the sign can be positive or negative.
- f Cross elasticity :: Ec = (dQa / Qa) x (Pb / dPb), or midpoint: [dQa / avg Qa] / [dPb / avg Pb] :: Qa = quantity of good A, Pb = price of good B :: Substitutes: price of A 110 -> 100, quantity of B 200 -> 150: (-50 / 175) / (-10 / 105) = -0.286 / -0.095 = +3.0 :: Book rounds to 3.01; never drop the sign
- eg Complements: price of A 100 -> 110, quantity of B 200 -> 150: -0.286 / +0.095 = -3.0.
| Relationship | Sign | Example in the text |
| * Substitutes | Positive (+) | Lipton vs Supreme tea bags; higher value = closer substitutes |
| * Complements | Negative (-) | Shoes and laces, phone and charger; bigger negative = stronger complementarity |
| Independent goods | Zero or near zero | No link between the two goods |

## concept Determinants and uses of elasticity of demand | 77-78
- * Close substitutes -> more elastic (coffee price up, people drink tea); no substitutes in the price range -> inelastic.
- * Necessities (salt) -> inelastic; luxuries and comforts -> relatively elastic.
- * Habit and brand loyalty -> inelastic (tobacco, TV shows, hand wash).
- * Small share of income spent (tomato ketchup) -> inelastic.
- * Longer time period -> more elastic, as buyers need time to try alternatives (chicken price up 10%, switch to other meat gradually).
- Complementary goods used jointly (bread and butter, TV and electricity) also affect how responsive demand is.
- * Price setting: elastic goods cannot be priced high (buyers switch); inelastic necessities can.
- * Finance minister: taxing inelastic goods (tobacco, electricity, luxury cars and flats) keeps demand and raises revenue; taxing elastic goods cuts demand and revenue.
- * Monopolists: inelastic -> higher price, smaller quantity; elastic -> keep price low and stimulate demand with promos and advertising.
- Transport fares: buses and taxis (elastic, substitutes like rail, Uber, InDrive) priced low; air travel (inelastic) priced high.
- Balance of trade: elastic foreign demand keeps export earnings low; countries want inelastic demand abroad so they can raise prices.
- Recessions: helps firms predict which products will be hit and how hard.

## formula Price elasticity of supply | 79-81
- * Always positive, because price and quantity supplied move together.
- f Elasticity of supply :: Es = [(Q2 - Q1) / ((Q2 + Q1) / 2)] / [(P2 - P1) / ((P2 + P1) / 2)] :: Q = quantity supplied :: P 100 -> 200 (= 0.667): Q 50 -> 60 gives 0.18 / 0.667 = 0.27 inelastic; Q 50 -> 150 gives 1 / 0.667 = 1.5 elastic; Q 50 -> 100 gives 0.667 / 0.667 = 1 unit :: A negative Es means you swapped a figure
- * Straight-line supply curves: cutting the price axis -> elastic everywhere; cutting the quantity axis -> inelastic everywhere; through the origin -> unit elastic everywhere (not true for curved lines).
- * Perfectly elastic supply (Es = infinity): horizontal - any amount at one price, nothing if price dips below it (a short-run, single-price idea).
- * Perfectly inelastic supply (Es = 0): vertical - quantity fixed whatever the price.

## concept Determinants of supply elasticity and time | 81-83
- * More elastic when: many firms in the industry, stocks available, spare capacity, resources easy to switch to other products, short production process.
- * Less elastic when: few firms, no stock, working at full capacity, specialised resources, long production time.
| Period | Can output change? | Supply curve |
| Momentary / immediate market period | No time to change output | Perfectly inelastic (vertical) |
| Short run | Plant fixed; small changes in technique or use of resources | Relatively inelastic |
| * Long run | Everything adjustable, incl. plant size and buildings | Highly elastic |
- * Demand rise D -> D1 from long-run equilibrium P0: price jumps to Pm in the momentary period, eases to Ps in the short run, settles at PL in the long run - longer time, more elastic supply, smaller price rise.

## exam How this chapter is tested in the CBE | 68-93
- ! Numeric entry is the core: compute PED (midpoint, point or arc as the question signals), income or cross elasticity, or elasticity of supply - show the two percentage changes then divide.
- ! Reverse questions: given PED and a % price change, find the new quantity (% change in Q = PED x % change in P).
- ! Interpret: the sign of income elasticity (normal vs inferior) and of cross elasticity (substitute vs complement); the size against 1 for elastic / inelastic.
- ! Total outlay MCQs: price and spending moving in the same direction = inelastic; opposite = elastic; spending unchanged = unity.
- ! Formulas to memorise: midpoint PED, point dQ / dP x P / Q, arc (Q1 - Q0) / (Q1 + Q0) x (P1 + P0) / (P1 - P0), geometric lower / upper, cross and supply versions.

## mistakes Common MCQ traps | 68-83
- x Dropping the sign on income or cross elasticity - the sign carries the answer.
- x Using averages in point elasticity (it uses the original P and Q).
- x Thinking a straight-line demand curve has one elasticity throughout - only its slope is constant.
- x Saying a price rise on an inelastic good lowers revenue - it raises it.
- x Expecting supply to be elastic in the momentary period - it is perfectly inelastic.

## recall Quick recall | 68-85
- PED = % change in Qd / % change in P; use absolute value.
- E > 1 elastic, E < 1 inelastic, E = 1 unit, 0 perfectly inelastic, infinity perfectly elastic.
- Elastic: price and revenue opposite; inelastic: same direction.
- Total outlay method (Marshall) gives direction only.
- Midpoint uses averages; point uses original values.
- Arc = (Q1 - Q0) / (Q1 + Q0) x (P1 + P0) / (P1 - P0).
- Geometric = lower segment / upper segment.
- Income elasticity: + normal, - inferior, > 1 luxury.
- Cross elasticity: + substitutes, - complements, 0 independent.
- Elastic demand: substitutes, luxuries, big income share, long time.
- Tax inelastic goods for revenue.
- Es always positive.
- Supply line through origin = unit elastic.
- Momentary perfectly inelastic, short run inelastic, long run highly elastic.
