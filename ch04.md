## concept Production and the production function | 96-97
- * def Production function :: The technical link between a firm's inputs and its output - the most output obtainable from a given input mix, written Q = f(L, K).
- f Average product :: APL = Q / L (or APK = Q / K) :: Q = total product, L = units of labour, K = units of capital :: 30 units from 3 workers -> APL = 10 :: AP is output per unit of input, not the extra output
- f Marginal product :: MPL = change in Q / change in L :: Shows the contribution of one more unit of input; it is the slope of the TP curve :: TP rises 15 -> 30 when labour goes 2 -> 3, so MPL = 15 :: Use the change, not the totals
- * Short run = at least one input fixed (plant capacity fixed; only labour, materials, utilities vary). Long run = every input can be changed.
- eg Garment unit at 100 units: extra shifts or overtime reach 200 units in the short run; a 5,000-unit order needs new plant and building, i.e. the long run.

## rule Law of variable proportions (diminishing returns) | 98-99
- * Adding more of one input (L) to a fixed input (K) makes that input's marginal product fall eventually.
- Assumptions: short run only; labour is the only variable input; technology constant; all units of input equally efficient; inputs can be combined freely.
| Labour | TP | MP | AP |
| 1 | 5 | 5 | 5 |
| 2 | 15 | 10 | 7.5 |
| 3 | 30 | 15 | 10 |
| * 4 | 40 | 10 | 10 |
| 5 | 45 | 5 | 9 |
| * 6 | 45 | 0 | 7.5 |
| 7 | 40 | -5 | 5.7 |
- * Stage I increasing returns (MP rising); Stage II diminishing returns (MP falling but TP still rising); Stage III negative returns (MP below zero, TP falling).
- * MP cuts AP where AP is at its highest; TP is at its peak when MP = 0.
- tip In the table: MP = AP = 10 at the 4th worker (AP peak); MP = 0 at the 6th worker (TP peak of 45).

## formula Short-run cost family | 101-103
- * f Total economic cost :: Explicit cost + implicit cost :: Explicit = amounts recorded in the books; implicit = opportunity cost of owner's resources :: Zain gives up Rs 100,000 a month salary to start a business -> that salary is an implicit cost :: Accountants record only the explicit part
- * f Total cost :: TC = TFC + TVC :: TFC stays the same at every output; TVC moves with output :: TFC 100 + TVC 250 = TC 350 :: So TC is always above TVC by TFC
- f Average costs :: AFC = TFC / Q; AVC = TVC / Q; ATC = TC / Q = AFC + AVC :: Q = units produced :: TC 350 at Q 10 -> ATC 35 :: AFC keeps falling as Q rises
- * f Marginal cost :: MC = change in TC / change in Q :: Extra cost of one more unit; slope of the TC curve :: TC rises 350 -> 380 as Q goes 10 -> 11, so MC = 30 :: Fixed cost does not affect MC
- * MC below AC pulls AC down; MC above AC pushes AC up; MC crosses AC at the lowest point of AC.
- Product and cost curves are mirror images: while MP rises MC falls; MC starts rising after MP peaks; MP = AP at the AP peak, MC = AC at the AC minimum (diminishing returns is also called the law of increasing cost).

## concept Long run - returns to scale and economies of scale | 100-105
- * Returns to a factor = output response to changing ONE input; returns to scale = response when ALL inputs change together.
  - Increasing (output grows faster than inputs - usual on expansion), constant (doubling inputs doubles output), diminishing (output grows more slowly - said to be rare).
  - eg Book table (labour + land, 1:2 mix): marginal returns 4, 6, 8 rising, then 10, 10, 10 constant, then 8, 6 falling.
- * No fixed cost in the long run, so TC = TVC and only ATC is used; the long-run ATC is built from many short-run ATC curves (one per plant size).
- * def Economies of scale :: Factors that make long-run average cost fall as output grows.
  - Sources: specialised labour, better large-scale technology, bulk-buying discounts, cheaper capital, in-house repair and maintenance, start-up costs spread over more units, advertising cost per unit falling.
- * def Diseconomies of scale :: Factors that make long-run average cost rise once output passes a certain size.
  - Causes: costly coordination, slow decisions through management layers, staff overheads growing faster than output, labour unrest.
- Long-run ATC falls (Q1 -> Q2, cost C1 -> C2) while economies last, is flat when neither applies, then rises with diseconomies.

## formula Firm's revenues | 106-112
- f Total revenue :: TR = P x Q :: P = selling price, Q = units sold :: 5 units at Rs 10 = Rs 50 :: --
- * f Average revenue :: AR = TR / Q = (P x Q) / Q = P :: AR is always the price :: TR 24 on 3 units -> AR = Rs 8 = price :: --
- * f Marginal revenue :: MR = change in TR / change in Q :: Revenue from selling one more unit; slope of TR :: Monopoly table: TR 24 -> 28 as Q goes 3 -> 4, MR = 4 :: Not the same as price when the demand curve slopes down
- * Perfect competition: price fixed at Rs 10 by the market, so P = AR = MR = 10 at every output.
- * Monopoly: falling demand curve, so AR = P > MR. Book table: P 10 down to 1; TR peaks at 30 (Q 5-6) where MR = 0, then falls as MR turns negative (-2 ... -8).

## process Perfect competition - equilibrium and profit | 107-110
- * Features: many buyers and sellers; identical product; free entry and exit; full price knowledge; no transport cost; perfectly mobile factors; firms are price takers; no advertising in price.
- * Necessary condition MC = MR; sufficient condition: MC = MR with MC rising.
- f Profit :: Profit = TR - TC :: TR > TC profit; TR < TC loss; TR = TC break-even :: TR 500, TC 420 -> profit 80 :: Economic TC includes implicit cost
- * f Accounting vs economic profit :: Accounting profit = TR - explicit cost; Economic profit = accounting profit - implicit cost :: Implicit = salary or rent the owner gives up :: Zain: TR 200,000 - (rent 50,000 + staff 35,000) = accounting profit 115,000; less forgone salary 125,000 = economic LOSS 10,000 a year :: Do not stop at accounting profit
- def Normal profit :: The least profit that keeps firms in the industry without drawing new ones in; TR just covers explicit plus implicit cost.
- Super-normal profit (short run): price above ATC at the MC = MR output.
- Sub-normal profit (normal loss): price below ATC but above AVC - variable cost covered, part of fixed cost not; the firm carries on.
- * ? Short run: does price (AR) at least cover AVC? :: keep producing, even if P < AC :: shut down (AVC > AR, TR < TVC)
- * Long run: entry removes super-normal profit and exit removes losses, so only normal profit remains.

## concept Monopoly | 110-114
- * Features: one seller (the firm is the industry); heavy entry barriers; no close substitutes; price maker.
- eg Pakistan: SSGC and SNGPL (gas), WAPDA (power), PTCL (telecoms).
- * Barriers: control of key inputs; structural barriers such as economies of scale (natural monopoly); cheaper production methods; predatory (dumping) pricing; regulatory licences; legal barriers - patents and exclusive rights.
- * Price and output set at MC = MR in the short run; super-normal profit can last into the long run.
- Against: higher prices; loss of consumer surplus; weak incentive to innovate (organisational slack); diseconomies of large scale; price discrimination; poorer quality; inefficient use of resources.
  - def Productive inefficiency :: Not producing at the lowest possible average cost.
  - def X-inefficiency :: Costs higher than needed because the firm has no pressure to control them (actual AC above potential AC).
- In favour: stable prices; economies of scale (case for natural monopolies); scale to compete abroad; profits to fund R&D; long-term investment; state monopolies supplying essential public utilities.
- * def Price discrimination :: Selling the same product to different buyers at different prices to raise profit.
  - Preconditions: the firm is a price maker; markets can be separated (income or elasticity); resale between segments can be blocked.
  - eg Peak / off-peak electricity, weekend cinema prices, bulk discounts, off-season price cuts; domestic vs commercial electricity tariffs.

## concept Monopolistic competition and oligopoly | 115-120
- Monopolistic competition
  - * Mix of monopoly and competition: many firms, each with a small share, selling differentiated products, with free entry and exit.
  - Brand loyalty and non-price competition (advertising, product development, distribution, after-sales service).
  - * Firm's demand curve slopes down but is relatively elastic because close substitutes exist.
  - Short run at MC = MR: super-normal profit if AR > ATC, normal if AR = ATC, sub-normal if AR < ATC. Long run: normal profit only (AR = LATC).
  - eg Hand wash brands, restaurants, shoe outlets, hair salons.
  - Pros: low barriers, more choice, less inefficient than monopoly, better-informed buyers. Cons: artificial differentiation, wasteful advertising, higher cost than perfect competition.
- Oligopoly
  - * Few sellers (book: 2 to 20) of similar or differentiated goods; key feature is interdependence - each firm's move affects rivals.
  - Other features: heavy advertising, firms of unequal size, indeterminate demand curve, high entry barriers (long-run super profit), homogeneous or differentiated output, buyers lack information.
  - eg Media, automobiles, airlines, cellular services, beverages.
  - * def Price cartel :: A group of firms agreeing together on market price and output, typically by restricting supply through quotas (e.g. OPEC).
    - Needs: very few well-known firms, openness on costs, similar costs and products, a dominant firm, entry barriers, a stable market, no government interference - so cartels are rare.
    - x Cartel price Pc tempts each member to produce more (Qs), which undermines the agreement.
    - Harm: high prices, hidden information, restricted output, poor quality.
  - * Non-collusive / kinked demand curve: firms act independently with roughly equal shares; the curve bends at the current price P*.
    - Price rise above P*: rivals ignore it, demand is elastic, the firm loses customers.
    - Price cut below P*: rivals match it, demand is inelastic, little gain in sales.
    - The kink splits the MR curve into two separate segments.
  - Pros: possible price setting, large and lasting profits, easy price comparison, stable prices for planning. Cons: price setting hurts buyers, small firms' innovation stifled, little incentive to improve, price wars.

## compare The four market models | 107-120
| Point | Perfect competition | Monopolistic competition | Oligopoly | Monopoly |
| * Number of sellers | Very many | Many | Few | One |
| Product | Identical | Differentiated | Similar or differentiated | No close substitute |
| * Entry barriers | None | Few | Heavy | Heavy |
| Price power | Price taker, P = AR = MR | Some, elastic demand | Interdependent | Price maker, P > MR |
| * Long-run profit | Normal | Normal | Super-normal possible | Super-normal |

## concept Globalization and firm behaviour | 121
- def Globalization :: Spread of business, knowledge, technology, goods and services beyond (and within) national borders, not just exporting.
- * Lower trade barriers push firms from weak to strong competition and break up monopolies.
- Effects: division of labour, economies of scale, more competition, higher productivity, easier access to capital - all lowering cost.
- x Costs: harm to infant industries, structural unemployment, environmental worries, trade imbalances, inflation risk.

## mistakes Common traps | 98-120
- x Applying diminishing returns to the long run - it needs at least one fixed input.
- x Treating normal profit as an explicit cost the accountant records.
- x Shutting down when P < ATC; the firm continues while P covers AVC.
- x Assuming MR = price for a monopolist (MR is below price).
- x Reversing the kinked curve: elastic ABOVE the kink (rivals ignore rises), inelastic BELOW (rivals match cuts).
- x Forgetting implicit cost when judging whether a venture is economically profitable.

## recall Quick recall | 96-123
- APL = Q / L; MPL = change in Q / change in L.
- Stages: increasing, diminishing, negative returns.
- TC = TFC + TVC; ATC = AFC + AVC.
- MC = change in TC / change in Q; cuts AC at its minimum.
- Economic cost = explicit + implicit.
- Economic profit = accounting profit - implicit cost.
- AR = P; perfect competition P = AR = MR.
- Profit maximised where MC = MR with MC rising.
- Shut down if AR < AVC.
- Long run in competition: normal profit only.
- Monopoly: AR > MR, barriers, price discrimination.
- Oligopoly: interdependence, cartels, kinked demand.
- Globalization raises competition and cuts cost.
