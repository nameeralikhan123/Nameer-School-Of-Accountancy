## concept Macroeconomics and its objectives | 133-134
- * Macroeconomics looks at the economy in aggregate - national income and output, unemployment, inflation and fluctuations - while microeconomics looks at individual prices and markets.
- Born out of the Great Depression of the 1930s; Keynes (General Theory, 1936) made effective demand the key driver of national income, against the Classical focus on supply.
- * Usual government objectives: economic growth; low inflation (some is unavoidable with growth); low unemployment; balance of payments equilibrium.

## def National income - meaning and rules | 135
- * def National income :: The money value of all final goods and services a country produces in a period, normally one year (Samuelson's "money measure" of the annual flow).
- National income, national output and national product are used interchangeably.
- * Count only final goods (no intermediate goods), only money values, only one year, only legal production.

## formula GDP, GNP and NNP | 135-136
- * f Gross domestic product :: GDP = C + I + G + (X - M) :: C consumption, I investment, G government spending, X exports, M imports :: Income of foreign engineers working in Pakistan is in Pakistan's GDP; Pakistani doctors working abroad are not :: GDP is about location (domestic resources), not nationality
- * f Gross national product :: GNP = GDP + net income from abroad :: Net income = income received from abroad - income paid abroad :: 500 + (250 - 200) = Rs 550bn :: Net income from abroad can be negative
- * f Net national product :: NNP = GNP - depreciation (capital consumption) :: Depreciation = fall in asset value from use during the year :: 550 - (plant 20 + building 30) = Rs 500bn :: GNP is therefore always above NNP
- * f Real GDP :: Real GDP = Nominal GDP / GDP deflator :: Nominal = current prices; real = base-year prices; deflator = price index (inflation measure) :: 5,000 units at current Rs 100 = 500,000 nominal; at base-year Rs 50 = real GDP 250,000 (deflator 200%) :: With rising prices nominal exceeds real
- def Nominal GDP :: GDP valued at the current period's prices, so it includes the effect of inflation.
- def Real GDP :: GDP valued at base-year prices; inflation-corrected, so the better guide to growth.

## formula Market price, factor cost, personal and disposable income | 137-138
- * f Factor cost vs market price :: NNPfc = NNPmp - indirect taxes + subsidies (NNPmp = NNPfc + indirect taxes - subsidies) :: Indirect taxes e.g. sales tax, excise; subsidies e.g. cheaper utilities or inputs :: NNPfc 500 + tax 50 - subsidy 30 = NNPmp Rs 520bn :: The factor price adjustment is indirect taxes and subsidies only
- * f Personal income :: PI = NI - corporate profit tax - undistributed profit - social security contributions + transfer payments :: Transfer payments = unearned income received without productive work :: 500 - (50 + 30 + 25) + 45 = Rs 440bn :: Transfers are ADDED here but excluded from national income
- * f Disposable personal income :: DPI = PI - personal (direct) taxes, or Yd = Y - T :: Personal taxes e.g. income tax, wealth / property tax :: 440 - (80 + 60) = Rs 300bn :: Deduct only direct taxes
- * f Per capita income :: National income / population :: Average income; a guide to living standards :: Rs 240bn / 120m people = Rs 2,000 :: Watch billions vs millions
- tip Undistributed profit = income earned but not received; transfer payment = income received but not earned.
- tip Size order: GNP > NNP > PI > DPI (DPI the smallest).

## process Circular flow of national income | 139
- * Households supply land, labour, capital and enterprise to firms and receive rent, wages, interest and profit; they spend this on firms' goods and services, so income keeps circulating.
- * Leakages (withdrawals): saving, taxes, imports. Injections: investment, government spending, exports.
- Financial institutions sit between savers and investors.
- x Investment is an injection, not a withdrawal; postponed consumption (saving) is a leakage.

## process Product approach and value added | 140-141
- * Add the market value of final output of goods (agriculture, manufacturing) and services (individual, institutional); add net income from abroad for GNP; deduct depreciation for NNP.
- eg Manufacturing 100 units x Rs 20m = 2,000; services 300 x Rs 15m = 4,500 -> GDPmp 6,500; + net income abroad 500 = GNPmp 7,000; - depreciation 2,000 = NNPmp 5,000 (Rs m).
- * f Value added :: GDP = sum of value added at each stage = value of the final product :: Value added = stage's output value - value of inputs bought :: Cotton 100, yarn 200 (+100), fabric 250 (+50), shirt 380 (+130): value added 100 + 100 + 50 + 130 = 380; adding full stage values (100 + 200 + 250 + 380 = 930) double counts :: Also: sales 45bn - bought-in goods 10bn = GDP 35bn
- Precautions: avoid double counting; ignore free services (housework, parent driving children, kitchen gardening); exclude resale of used goods (a car resold in the same year adds nothing).

## process Income and expenditure approaches | 141-143
- * Income approach: add factor rewards - rent + wages + interest + pre-tax profit; gives national income at factor cost.
- eg Rent 100 + wages 200 + interest 250 + profit 150 = NI at factor cost Rs 700m.
- Income approach precautions: exclude transfer payments (pensions, gifts, scholarships) and illegal income (theft, smuggling, bribery).
- * f Expenditure approach :: Y = C + I + G + (X - M) :: C excludes house purchases; I = new factories, plant, warehouses; G = development and non-development spending; X - M = export surplus :: 100 + 200 + 250 + 150 = Rs 700m :: Exclude second-hand goods and count each spend once
- eg Self-test style: C 25,000 + I 5,000 + G 5,000 + (4,000 - 6,000) = GDPmp 33,000; + net factor income 2,000 = GNPmp 35,000; - depreciation 1,000 = NNPmp 34,000; - GST 4,000 + subsidies 1,000 = NI at factor cost 31,000 (Rs bn).
- * With all precautions applied, the three approaches give the same national income.

## concept Difficulties and uses of measurement | 144
- * Difficulties: lack of trained staff; illiteracy and poor records; weak collection procedures; unpaid work (housewives, own-use farm output) left out; barter ignored or estimated; undocumented (black / shadow) economy; price fluctuations; earnings of foreign firms.
- * Uses: judge economic performance; estimate per capita income and living standards; study income distribution among factors; base economic planning (commercial, monetary, fiscal policy); compare countries.

## concept Aggregate demand | 145-147
- * def Aggregate demand :: Total spending on goods and services in an economy at a given general price level over a given period.
- * Components: C + I + G + (X - M). AD slopes downward against the price level.
- * A change in the price level moves along AD; AD shifts only when a component changes.
  - Shift out: consumers spend more, investor optimism, more infrastructure spending, exports more attractive, imports less wanted.
  - Shift in: e.g. lower government spending.
- def Effective demand :: Keynes's idea of spending actually made out of current income, not what would be spent if the economy were at full potential.
- x Demand for labour is factor demand, not part of AD for goods and services.

## concept Aggregate supply - SRAS, LRAS and Keynes | 147-150
- * def Aggregate supply :: Total output firms in an economy are willing to supply at a given general price level over a given period.
- * SRAS slopes upward: a higher price level brings more output.
- SRAS shifts with: labour and capital productivity, size and quality of capital stock and workforce, wage costs, producer taxes or subsidies, inflation expectations.
- * def Full employment (Yf) :: All available resources fully used, so no further output is possible.
- * LRAS is vertical at Yf: independent of the price level and equal to the economy's productive potential.
- LRAS shifts right only with permanent gains in potential: better labour skills, better technology, new natural resources.
- * Keynesian AS: flat (horizontal) while spare capacity exists, vertical at full employment; Keynes saw no short-run / long-run split.

## process Equilibrium and output gaps | 151-154
- * Equilibrium where AD = SRAS; full macro equilibrium where this also meets LRAS.
- * def Output gap :: Actual output less the economy's productive potential.
- * Negative (deflationary / recessionary) gap: AD below Yf, resources idle, downward pressure on prices (e.g. COVID-19 slump).
  - Remedies in the self-tests: more government or consumer spending.
- * Positive (inflationary) gap: AD above Yf, resources cannot meet demand, price level rises; caused by rising C, I or G.
  - Remedies: cut government spending, raise direct taxes or interest rates; NOT more government spending.
- AD shifts right: price and output both rise. SRAS shifts right: price falls, output rises.
- ? Do AD and SRAS both rise? :: if AD rises more, price and output rise; if SRAS rises more, price falls and output rises :: look at the single shift
| Change | Price level | Output |
| * AD up (below Yf) | Rises | Rises |
| SRAS up | Falls | Rises |
| * AD up beyond Yf | Rises | No more output (inflationary gap) |
| Wage rate up (SRAS in) | Rises | Falls |

## mistakes Common traps | 135-154
- x Adding intermediate goods or second-hand sales, which double counts.
- x Treating transfer payments as part of national income (they enter only PI).
- x Using GDP when the question wants income of nationals abroad (that is GNP).
- x Getting the factor cost sign wrong: subtract indirect taxes, add subsidies.
- x Calling a change in the price level a shift of AD or AS.
- x Fixing an inflationary gap with more government spending.

## recall Quick recall | 133-157
- NI = money value of final goods and services in a year.
- GDP = C + I + G + (X - M).
- GNP = GDP + net income from abroad.
- NNP = GNP - depreciation.
- NNPfc = NNPmp - indirect tax + subsidies.
- PI = NI - corporate tax - undistributed profit - social security + transfers.
- DPI = PI - personal taxes.
- Real GDP = nominal GDP / deflator.
- Leakages: S, T, M; injections: I, G, X.
- Three approaches: product, income, expenditure - same answer.
- AD slopes down; SRAS up; LRAS vertical at Yf.
- Keynesian AS: horizontal then vertical.
- Output gap = actual - potential output.
- AD > Yf = inflationary gap; AD < Yf = deflationary gap.
